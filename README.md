# Sunroom walkthrough

A browser-based architectural concept walkthrough.

Open https://nitini.github.io/sunroom-walkthrough/ on a laptop. Click Explore; use the mouse to look, WASD to walk, E/Q to rise or descend, and Esc to release the pointer.

Includes day/evening presets and representative furnishings and surroundings. Asset and software credits are in LICENSES.txt.
